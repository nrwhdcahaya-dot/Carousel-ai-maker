# Carousel AI Maker — Vercel

1. Upload folder ini ke GitHub.
2. Import repository ke Vercel.
3. Di Vercel: Project Settings → Environment Variables.
4. Tambahkan `OPENAI_API_KEY` dengan API key OpenAI Anda. Jangan menaruh key di HTML/JavaScript.
5. Deploy / redeploy.
6. Buka URL Vercel dari HP.

Fitur: membuat 7 slide, edit slide, generate gambar AI per slide, generate semua gambar, dan cetak/simpan PDF.

Catatan: biaya penggunaan OpenAI API mengikuti harga dan kebijakan akun API Anda.
